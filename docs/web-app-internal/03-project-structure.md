## 3. Project Structure

### 3.1 Folder Organization

```text
electric-wealth-web/
├── index.html                 # SPA shell: #root, favicon, color-scheme meta
├── vite.config.ts             # React plugin, port 5173, /api proxy
├── tsconfig.json              # references tsconfig.app.json + tsconfig.node.json
├── package.json / package-lock.json
├── .env.example  .nvmrc  .gitignore
├── public/
│   └── favicon.svg
└── src/
    ├── main.tsx               # QueryClient + provider tree, imports ./i18n and ./styles.css
    ├── App.tsx                # route tables (signed-out / signed-in), NotFound
    ├── styles.css             # all styles: tokens, themes, layout, components (1,582 lines)
    ├── api/
    │   ├── schema.d.ts        # GENERATED by `npm run gen:api` — do not edit
    │   ├── client.ts          # openapi-fetch client, middleware, ApiError, unwrap()
    │   └── hooks.ts           # queryKeys + one TanStack Query hook per API call
    ├── auth/
    │   ├── AuthContext.tsx    # AuthProvider / useAuth: phases, login, MFA, logout, idle + refresh timers
    │   └── tokenStore.ts      # sessionStorage-backed token holder
    ├── components/
    │   ├── Layout.tsx         # signed-in shell: top bar, nav, bell, language toggle, user menu, <Outlet/>
    │   ├── ui.tsx             # shared presentational components
    │   └── charts.tsx         # SVG AllocationBar, PerformanceChart, PriceChart
    ├── features/              # one folder per product area, one file per page
    │   ├── accounts/  advisor/  auth/  dashboard/  documents/
    │   └── education/  goals/  market/  notifications/  profile/  settings/
    ├── i18n/
    │   ├── index.ts           # i18next init, getAppLocale / setAppLocale
    │   ├── en-CA.json
    │   └── fr-CA.json
    └── lib/
        ├── format.ts          # Intl-based money/percent/date/bytes formatters
        └── deepLinks.ts       # electricwealth:// → web route mapping
```

There are no `hooks/`, `store/`, `services/`, `types/` or `utils/` folders: data access is `api/`, shared UI is
`components/`, pure helpers are `lib/`.

### 3.2 Naming Conventions

| Element | Convention | Examples |
|---|---|---|
| Page files | `PascalCase` + `Page.tsx`, one exported page per file | `AccountDetailPage.tsx`, `GlossaryPage.tsx` |
| Grouped auth screens | One file may export several small pages | `AuthPages.tsx` exports `AuthCard`, `LoginPage`, `MfaPage` |
| Page-local sub-components | Unexported `function` in the page file | `NicknameEditor`, `PerformanceSection`, `ShareDialog`, `GoalForm`, `BookingPanel`, `MeetingRow` |
| Components | Named exports only (no default exports) | `export function Card(...)` |
| Hooks | `use` + noun (query) or `use` + verb + noun (mutation) | `useAccounts`, `useUpdateAccount`, `useToggleWatchlist` |
| Query keys | Arrays from the `queryKeys` object; first element is the area | `['accounts', page]`, `['advisor', 'messages']` |
| API types | `Schemas['<OpenAPI schema name>']` | `Schemas['GoalCreateRequest']` |
| CSS classes | BEM-like: `block`, `block__element`, `block--modifier`; state as `is-*` | `account-row__name`, `btn--primary`, `is-active` |
| Translation keys | `<section>.<snake_case_key>`; web-only strings under `web.` | `accounts.hide_balances`, `web.not_on_web` |
| Storage keys | `ew_` prefix | `ew_tokens` (sessionStorage), `ew_locale` (localStorage) |
| Window events | `ew:` prefix | `ew:unauthorized` |
| Imports | Relative paths, no aliases; `import type` for types (`verbatimModuleSyntax`) | `../../api/hooks` |

### 3.3 Module and Dependency Registration

There is no DI container. Everything is wired by module imports and React context in
[main.tsx](../../src/main.tsx):

```tsx
const queryClient = new QueryClient({ defaultOptions: { queries: { staleTime: 30_000, retry: …, refetchOnWindowFocus: false } } });

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <BrowserRouter>
        <AuthProvider>
          <App />
        </AuthProvider>
      </BrowserRouter>
    </QueryClientProvider>
  </StrictMode>,
);
```

Side-effect imports in `main.tsx`: `./i18n` (initialises i18next before first render and sets `<html lang>`) and
`./styles.css`. Module singletons: `api` (openapi-fetch client with middleware, [client.ts](../../src/api/client.ts)),
`tokenStore` ([tokenStore.ts](../../src/auth/tokenStore.ts)) and the i18next instance.

Ordering constraints: `AuthProvider` must be inside `QueryClientProvider` because it calls `useQueryClient()` to clear
the cache on logout. `App` uses `useLocation`, so it must be inside `BrowserRouter`.

To add a page: create `src/features/<area>/<Name>Page.tsx`, add a `<Route>` in [App.tsx](../../src/App.tsx), add
hooks to [hooks.ts](../../src/api/hooks.ts), add strings to both locale files. Checklist in
[23.3](23-quick-reference.md#233-feature-development-checklist).
